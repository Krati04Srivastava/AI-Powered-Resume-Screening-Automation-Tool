# AI-Powered Resume Screening Automation Tool

## Overview

A Python-based Resume Screening Automation Tool that processes multiple PDF resumes, extracts candidate information, compares skills with a job description, calculates ATS scores, and generates a ranked CSV report.

## Features

- Read multiple PDF resumes
- Extract candidate name
- Extract email address
- Extract phone number
- Extract technical skills
- Compare with Job Description
- Calculate ATS Match Score
- Generate CSV Report
- Rank Candidates

## Technologies

- Python
- Pandas
- PDFPlumber
- Regular Expressions
- File Handling
